# **Judging System for Low Kick / Kickboxing – Final Technical Specification**

---

## **1️⃣ Цель системы**

Система предназначена для:

* автоматического подсчёта ударов бойцов в раундах
* фиксации нокдаунов и сильных ударов
* учёта официальных предупреждений и штрафных баллов
* определения победителя раунда и боя
* обработки edge cases, включая ничьи и технические ошибки

---

## **2️⃣ Основные правила подсчёта**

| Тип события                     | Баллы                       | Особенности                                                                                                                                                 |
| ------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Обычный удар**                | 1                           | Учитывается при подсчёте очков. Если удары обоих бойцов были **одновременно**, они **не учитываются** для определения победителя, но сохраняются в истории. |
| **Нокдаун / сильный удар**      | 3                           | Всегда засчитывается, не подчиняется правилу «одновременные удары».                                                                                         |
| **Одновременные обычные удары** | 0 (для подсчёта победителя) | Считаются для истории, но не влияют на победителя раунда.                                                                                                   |
| **Undo**                        | -1                          | Судья может отменить **последний свой удар** в течение раунда и **5 секунд после окончания раунда**.                                                        |
| **Official Warning**            | 0                           | Фиксируется за нарушение правил, влияет на дисциплинарный протокол, но не на очки.                                                                          |
| **Minus Point**                 | -3                          | Снимается 3 очка с бойца за серьёзное нарушение правил, фиксируется сразу и **не может быть отменён через Undo**.                                           |

---

## **3️⃣ Алгоритм подсчёта раунда**

1. Судьи нажимают **Red / Blue** за каждый чистый удар.
2. Система хранит историю всех нажатий.
3. **Одновременные удары** отмечаются, но не учитываются при определении победителя.
4. **Нокдауны и сильные удары** засчитываются сразу (+3 очка).
5. **Minus Points** снимаются сразу (-3 очка) и учитываются при подсчёте победителя.
6. После окончания раунда запускается **5-секундное окно** для Undo:

   * судьи могут отменять свои последние удары
   * результат пересчитывается автоматически
7. Определение победителя раунда:

   * если **баллы не равны** → победитель по очкам
   * если **баллы равны** → побеждает **тот, кто нанёс последний удар**

---

## **4️⃣ Алгоритм подсчёта боя**

1. Счёт по каждому раунду фиксируется после **5-секундного окна**.
2. Победитель боя определяется по большинству выигранных раундов.
3. В случае равного количества выигранных раундов:

   * используется **правило последнего удара раунда** для tie-breaker
   * если все раунды ничейные → бой считается **ничейным**

---

## **5️⃣ Архитектура системы**

### 5.1 Устройства судей

* Локальный таймер раунда
* Буфер кликов при потере соединения
* Undo для последних ударов
* Отправка данных с **отметкой времени** каждого удара
* Получение команд сервера **PAUSE / RESUME**

### 5.2 Сервер

* Принимает данные от всех судей
* Хранит историю ударов по каждому раунду
* Управляет состоянием раунда: `ROUND_NOT_STARTED`, `ROUND_RUNNING`, `ROUND_PAUSED`, `ROUND_ENDED`
* Обрабатывает победителя раунда и боя

---

## **6️⃣ Edge Cases, которые система учитывает**

1. Равное количество ударов у судьи → победа за **последний удар**, ничья только при 0:0
2. Равное количество раундов → победа за бойцу, который нанес последний удар раунда, иначе ничья
3. Противоположные решения судей → решает **простое большинство**
4. Судья не нажал ничего → раунд считается ничейным для этого судьи
5. Сильно выбивающийся судья → пока не учитывается (система доверяет всем)
6. Одновременные удары → не учитываются при подсчёте победителя
7. Очень близкая разница в ударах → правило последнего удара решает
8. Нокдаун / сильный удар → +3 очка, всегда засчитывается
9. Удар на границе раунда → засчитывается по таймеру устройства судьи
10. Техническая рассинхронизация / сетевые задержки → клики буферизуются на устройстве и проверяются по локальному таймеру
11. Отмена удара (Undo) → разрешена в течение раунда и **5 секунд после окончания раунда**
12. Слишком много ударов → система доверяет судье без ограничений
13. Потеря соединения → клики сохраняются на устройстве и засчитываются после восстановления
14. Undo после окончания раунда → разрешён, результат пересчитывается
15. Undo нескольких судей → пересчёт ведётся после каждого Undo, 5-секундное окно фиксирует окончательный результат
16. Последний удар был давно → побеждает тот, кто сделал последний удар
17. **Official Warning** → фиксируется, но не влияет на очки
18. **Minus Point** → снимается 3 очка, учитывается при подсчёте победителя

## **8️⃣ Выводы**

* Система учитывает **большинство реальных edge cases** турниров по Low Kick.
* Архитектура **клиент-сервер** с локальными таймерами судей минимизирует сетевые задержки и ошибки на границе раунда.
* Правило **«последний удар решает ничью»** полностью интегрировано.
* Undo и буферизация обеспечивают **гибкость и корректность результатов**.
* **Official Warnings и Minus Points** добавляют дисциплинарный контроль без нарушения автоматического подсчёта ударов.
